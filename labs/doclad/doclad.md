## Введение и актуальность

**Контекст:** В образовательном процессе РУДН и научных кластерах активно используются UNIX-подобные системы. Bash является стандартом, однако:
*   Многие legacy-системы (FreeBSD, Solaris, старые дистрибутивы) используют **tcsh** как shell по умолчанию.
*   Научное ПО часто требует специфических настроек окружения.

**Проблема:** Студенты и администраторы, привыкшие к bash, теряют время на отладку конфигов при переходе на tcsh.

**Актуальность:** Систематизация различий ускорит адаптацию и снизит число ошибок.

## Объект, предмет, новизна

*   **Объект исследования:** Процесс инициализации интерактивной командной оболочки.

*   **Практическая значимость:** Готовый справочник для миграции пользователей без потери функциональности.

## Ключевое различие: Иерархия загрузки

*Понимание этого — 50% успеха настройки*

| Тип сессии | tcsh | bash |
| :--- | :--- | :--- |
| **Системный login** | 1. `/etc/csh.cshrc` <br> 2. `/etc/csh.login` | 1. `/etc/profile` <br> 2. `/etc/profile.d/*` |
| **Пользовательский login** | 1. `~/.tcshrc` **(или .cshrc)** <br> 2. `~/.login` | 1. `~/.bash_profile` (или `~/.profile`) |
| **Интерактивный (новый терминал)** | `~/.tcshrc` | `~/.bashrc` |
| **Завершение сессии** | `~/.logout` | `~/.bash_logout` |

**Специфика tcsh:** `.tcshrc` выполняется *всегда* (как .bashrc), а `.login` — только при входе в систему (как .profile). Это разделение логичнее, чем в bash.

## Синтаксис: Переменные окружения

*Главный источник ошибок при миграции*

| Операция | bash (синтаксис) | tcsh (синтаксис) | Примечание |
| :--- | :--- | :--- | :--- |
| **Установка переменной** | `VAR="value"` | `set var = "value"` | В tcsh пробелы обязательны вокруг `=` |
| **Экспорт в окружение** | `export VAR="value"` <br> или <br> `VAR="value"; export VAR` | `setenv VAR "value"` | **Критично:** Никакого знака `=` !!! |
| **Добавление в PATH** | `export PATH=/new:$PATH` | `setenv PATH /new:$PATH` | Аналогично, без `=` |
| **Локальные переменные** | `local var="value"` (в функциях) | `set var = "value"` (всегда) | В tcsh `set` создает локальную переменную shell |

> **Пример ошибки:** `setenv PATH=/usr/bin` в tcsh не сработает. Верно: `setenv PATH /usr/bin`.

## Синтаксис: Алиасы и подстановка команд

| Аспект | bash | tcsh |
| :--- | :--- | :--- |
| **Простой алиас** | `alias ll='ls -la'` | `alias ll 'ls -la'` (пробел вместо `=`) |
| **Алиас с аргументами** | Используются функции <br> `myfunc() { ls -la "$@"; }` | Встроенная поддержка: <br> `alias jobs 'ps \!* \| grep user'` <br> (`\!*` — все аргументы) |
| **Подстановка команд** | `$(command)` или `` `command` `` | Только `` `command` `` (backticks) |
| **Подстановка истории** | `!!`, `!$`, `!100` | Аналогично: `!!`, `!$`, `!100` |

## Настройка приглашения (prompt)

*tcsh выигрывает в читаемости за счет форматных спецификаторов*

| Shell | Команда | Результат |
| :--- | :--- | :--- |
| **bash** | `PS1='\u@\h:\w\$ '` <br> `PS1='\[\033[01;32m\]\u@\h:\w\$\[\033[00m\] '` | `user@host:~$` <br> (зеленый текст через ANSI-коды) |
| **tcsh** | `set prompt = "%B%n@%m%b:%~ %# "` | **user@host:~ %** (жирный) |

**Расшифровка форматов tcsh (`%`):**
*   `%n` — username (`\u`)
*   `%m` — hostname (`\h`)
*   `%~` — текущий путь (`\w`)
*   `%B` / `%b` — bold on/off
*   `%d` — день недели, `%t` — время
*   `%#` — `%` для обычного пользователя, `#` для root

**Вывод:** В tcsh промпт настраивается декларативно, без эскейп-кодов.

## Автодополнение и история

| Функция | bash | tcsh | Вердикт |
| :--- | :--- | :--- | :--- |
| **Автодополнение команд** | Минимальное (только файлы). Требует `bash-completion` | Полноценное из коробки | **tcsh удобнее** |
| **Автодополнение переменных** | `$` + Tab | `$` + Tab | Одинаково |
| **Коррекция опечаток** | Нет | `set complete = enhance` | **Уникальная фича tcsh** |
| **Поиск по истории** | `Ctrl+R` (reverse-i-search) | `Ctrl+R` (аналогично) | Одинаково |
| **Список при двойном Tab** | `bind 'set show-all-if-ambiguous on'` | `set autolist` | Одинаково (разный синтаксис) |

**Ключевая настройка tcsh для автодополнения:**
```tcsh
set complete = (enhance complete)   # Учет регистра, исправление очевидных опечаток
set autolist                         # Показывать список вариантов
set correct = cmd                     # Автокоррекция команд
